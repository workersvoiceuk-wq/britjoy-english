# BritJoy English

## Proyecto

- La aplicación web y móvil vive en este repositorio. Usa las rutas y los IDs existentes de cursos y lecciones. Revisa `README.md` para desarrollo y `supabase/README.md` para el servidor de BritJoy.
- Ejecuta `npm test` y `npm run build`. Para cambios de interfaz ejecuta las pruebas de navegador pertinentes. Para Vida Diaria, sigue `docs/VIDA-DIARIA.md` en la rama que contiene el curso.
- Este repositorio es público. Los medios de pago, las claves y los datos de alumnos se guardan fuera del árbol y de la compilación pública.

## Trabajo compartido

- Usa GitHub como referencia compartida. Antes de editar, lee el PR o la tarea y confirma repositorio, rama y SHA. Elige una rama por tarea.
- ChatGPT/Codex coordina y puede revisar o implementar. Claude Code puede implementar y ejecutar las pruebas. Antigravity puede revisar código público y trabajar en su propia rama. Cualquier cambio de responsable se registra en el mismo PR.
- Mantén un solo editor por rama. Los demás revisan el SHA indicado o trabajan en una rama distinta. Si cambia el SHA durante una revisión, vuelve a verificar la diferencia.
- En el PR registra alcance, archivos modificados, pruebas ejecutadas, pruebas pendientes, bloqueos y siguiente responsable. Incluye evidencia que permita reproducir el resultado.
- Usa cuentas de prueba y datos sintéticos para facturación, acceso de alumnos y base de datos. Los cambios de producción requieren la autorización que corresponda a la tarea y una comprobación posterior.
- Guarda credenciales en el gestor de secretos autorizado. Comparte código privado o datos de usuarios solo mediante accesos autorizados para el repositorio y el proveedor concreto.
